# Hi there, I'm Mehmet Eren 👋 | Media Automation & AI Agent Developer

I build autonomous media systems, programmatic video engineering pipelines, and intelligent AI agent infrastructure. My work centers on creating open-source **Model Context Protocol (MCP)** servers, robust **FFmpeg** audio/video processing workflows, algorithmic **3D LUT** color grading automation, and developer-first tooling that connects large language models with real-world creative media software.

---

### 🚀 Featured Open-Source Project

#### 🎬 [mcp-video-studio](https://github.com/mehmeterenozturkk-max/mcp-video-studio)
> **A high-performance Model Context Protocol (MCP) server for automated video editing, FFmpeg media processing, and CapCut project generation.**

- **Autonomous Video Pipelines**: Granular FFmpeg operations for video filtering, audio ducking, format transformation, and automated multi-track rendering.
- **3D LUT & Visual Grading**: Automated cinematic color space transforms and LUT integration.
- **Timeline & Draft Automation**: Native CapCut draft schema synthesis directly from AI agent instructions.
- **Protocol First**: Built on FastMCP with asynchronous I/O and production-ready error handling.
